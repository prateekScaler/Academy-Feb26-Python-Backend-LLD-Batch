## How to Add Yourself

1. Fork this repository
2. Clone your fork locally
3. Create a branch: `git checkout -b add-student/your-name`
4. Add your row to the table below
5. Commit: `git commit -m "feat: Add [Your Name] to contributors"`
6. Push to your fork: `git push origin add-student/your-name`
7. Create a Pull Request!

## Badge of Honor

Once your PR is merged, you've officially made an open source contribution!

This is exactly how real open source projects work:
- You can't push directly to repositories you don't own
- You fork → clone → branch → commit → push → PR
- Maintainers review and merge your contribution
