What is about to happen

  1. We redirect you to Google. Look at the address bar: you will see our client_id, the scope we are asking for, and a code_challenge (a hash of a secret we kept).
  2. Google logs you in and asks your consent to share your name, email and picture with this app.
  3. Google sends you back to /oauth/callback/?code=...&state=.... That code is a one-time ticket — it is not a login by itself.
  4. Our server swaps the code for a token in a direct server-to-server call to Google, proving it is really us by sending the original PKCE secret.
  5. Our server fetches your profile with that token and shows it above.

This app never sees your Google password. You type it on Google's own page, on Google's own domain. All we ever receive is a short-lived code, and then a token that only grants the narrow permissions you approved.
