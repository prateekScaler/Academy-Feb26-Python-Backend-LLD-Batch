## Overview

Users search hotels by date range and room type, then book a room for those nights; availability must respect overlapping date ranges.

> **Difficulty:** Medium &nbsp;·&nbsp; **Key concepts:** Room types, date-range booking, availability

## Expectations

* Code should be functionally correct.
* Code should be modular and readable — clean, professional-level code.
* Code should be extensible and scalable — accommodate new requirements with minimal changes.
* Code should follow good OOP design principles (SOLID, and the right design patterns).

  1. Search hotels by city and check-in/check-out dates.
  2. A hotel has rooms of various types (single/double/suite) with prices.
  3. A room is bookable only if free for the entire date range.
  4. Booking a date range marks those nights unavailable for that room.
  5. Compute the price from nights × room rate.
  6. Support cancellation and refund per policy.
  7. Prevent overlapping bookings for the same room.
