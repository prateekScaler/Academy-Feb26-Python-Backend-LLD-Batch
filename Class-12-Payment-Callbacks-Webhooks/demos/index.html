Payment Flow Demos

See how different companies implement payment checkouts

🔄
Pattern 1: Full Redirect
User clicks "Pay" and is redirected to the payment gateway's website. Card details entered on Stripe/Razorpay domain. User returns after payment.
Used by: Small D2C brands, indie e-commerce, subscription sites
📦
Pattern 2: Embedded iframe
Checkout page looks like merchant's site, but card input is actually a Stripe/Razorpay iframe. Best of both worlds - seamless UX, no PCI burden.
Used by: Shopify stores, Frido, Boat, modern e-commerce
🏢
Pattern 3: Direct API
Large companies handle card data directly on their servers. Requires PCI DSS Level 1 certification - expensive and complex.
Used by: Amazon, Netflix, Uber (millions of transactions)
🔀
Callback + Webhook Flow
Interactive demo showing how callback (browser redirect) and webhook (server POST) happen simultaneously after payment.
Learn: Why both are needed, what to trust
