Callback + Webhook: Both Happen!

Watch the timeline to see how callback and webhook happen simultaneously but serve different purposes

Callback (Browser)
Webhook (Server)
Happen Together
CALLBACK T+0s
User clicks "Pay Now"
Customer submits payment on Razorpay/Stripe checkout. Browser is waiting for redirect...
WEBHOOK T+1s
Gateway processes payment
Razorpay/Stripe verifies card, contacts bank, runs fraud checks. User is still waiting...
CALLBACK T+3s
Browser redirects to /success
User sees "Thank you!" page on your site. URL: yoursite.com/success?payment_id=xxx
WEBHOOK T+3s to T+30s
Webhook POSTs to your server
Gateway's server calls POST /webhook/ with signed payload. Contains: payment status, amount, signature for verification.
WEBHOOK T+4s to T+31s
Your server processes webhook
1. Verify signature (HMAC SHA256)
2. Check idempotency (no duplicates)
3. Update order status in database
4. Return 200 OK

Callback tells the user what happened.
Webhook tells your server what happened.

Trust the webhook.
