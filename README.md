# Academy Feb 26 - Python Backend LLD Batch

Interactive course materials for the Python Backend Low Level Design module.

## Course Overview

A 12-week journey from zero to backend hero, covering Django, REST APIs, AWS deployment, payments, and more.

## Module Structure

| Week | Class | Topic | Restaurant Analogy Question |
|------|-------|-------|----------------------------|
| 1 | 01 | Module Overview, Intro to Backend | What is a restaurant? Who are the actors? |
| 1 | 02 | Git, Commits, Merge, Rebase | How do multiple chefs work on the same recipe book? |
| 2 | 03 | Git Remotes, Forks, Pull Requests | How do chefs across branches share recipes? |
| 2 | 04 | Django Apps, Views, URL Mapping | Who greets customers, takes orders, routes them? |
| 3 | 05 | Django Models and Admin | How does the kitchen track inventory? |
| 3 | 06 | REST Framework and Serializers | How do we design the menu and plate food? |
| 4 | 07 | Inheritance, IDs, Custom Queries | How do we handle dish categories and combos? |
| 4 | 08 | Cardinalities, N+1, Migrations | How do we manage ingredient relationships? |
| 5 | 09 | Exception Handling, Middlewares | What if a dish fails? How do we handle complaints? |
| 5 | 10 | Intro to AWS, EC2, RDS | How do we move to a commercial kitchen? |
| 6 | 11 | AWS VPC, Security Groups, Route 53 | How do we secure and set up the building? |
| 6 | 12 | Payment Callbacks, Webhooks | How does the payment terminal talk to the bank? |
| 7 | 13 | Reconciliation, Crons, Stripe | How do we handle daily accounting? |
| 7 | 14 | Pagination, Searching, Sorting | How do we organize a large menu efficiently? |
| 8 | 15 | Optimizing APIs, Redis, Resume Project | How do we make the kitchen faster? |

## How to Use

1. Open the class folder you want to present
2. Open `index.html` in a browser (preferably Chrome)
3. Use arrow keys or buttons to navigate
4. Interactive quizzes are embedded in the slides

## Keyboard Shortcuts

- `→` or `Space` - Next slide
- `←` - Previous slide

## Tech Stack Used in Course

- **Python** - Primary language
- **Django** - Web framework
- **Django REST Framework** - API development
- **PostgreSQL** - Database
- **Redis** - Caching
- **AWS** - Cloud deployment
- **Stripe** - Payment integration

## Prerequisites for Students

- Python basics (variables, loops, functions, classes)
- Data Structures (lists, dictionaries, sets)
- OOP Concepts (classes, inheritance)
- Terminal/Command line basics
- Curiosity!
